# Пояснение к базе знаний

Для задания 2 выбрана известная предметная область — космическая фэнтези-вселенная в стиле Star Wars.

Чтобы LLM не отвечала по памяти, все ключевые термины заменены на вымышленные названия:

- персонажи;
- организации;
- планеты;
- технологии;
- оружие;
- события;
- корабли.

Словарь замен находится в файле `terms_map.json`.

Финальная база знаний находится в папке `data/knowledge_base/` и содержит 32 Markdown-документа. Каждый документ описывает одну сущность: персонажа, планету, организацию, технологию или событие.

Тексты не являются копиями страниц fandom/wiki. Они подготовлены как очищенные краткие документы для учебного RAG-проекта и затем обработаны заменой терминов. Это позволяет проверить, что бот действительно использует локальный векторный индекс, а не знания LLM из pretraining.
